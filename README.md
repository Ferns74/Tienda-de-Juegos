Desarrollo de un sistema para escritorio para administración de una tienda de videojuegos utilizando visual basic y SQL Server Management 

## Instalación
Ejecutar los query en sql server 
En los archivos FrmRecibo.vb y FormLogin.vb poner la cadena de conexión de tu sql server 

## Herramientas 
Visual Studio 
SQL Server Management
